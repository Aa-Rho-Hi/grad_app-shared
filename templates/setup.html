Set up logins

Create the first Grad office login. From then on every page needs a sign-in; group leaders and professors request their own logins and you approve them on the Accounts page.

{# Carries the operator's claim token through the POST, so the form works from a ?token=… link without putting it in the action URL. #}

Stored as a salted PBKDF2 hash in config/users.yaml, never in the clear. A short password is fine while this only runs on your own machine; pick a real one before it's reachable from anywhere else. Delete that file and the app goes back to running without a login. There's no password reset — if you forget it, delete the file and set up again.
